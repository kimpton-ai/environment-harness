What am I looking at?

This is a read-only evidence viewer for environment sessions stored by EnvironmentHarness. It does not run agents or change the environment.

  1. Select an original or branched session on the left.
  2. Trace what each participant observed, attempted, and caused in the timeline.
  3. Compare two checked sessions to see their shared history, branch intervention, and recorded results.
