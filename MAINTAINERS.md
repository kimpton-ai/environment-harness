# Maintainers

The Kimpton AI maintainers own releases and repository policy for EnvironmentHarness.

- `@kimpton-ai/maintainers` — general maintenance and release review
- `@kimpton-ai/security` — security policy, credentials, workflows, dependencies, and cooldown exceptions

At least one independent maintainer review and all applicable CODEOWNERS reviews are required before merge. Maintainer status is granted or removed through a reviewed pull request to this file.
